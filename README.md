# Cutline — рабочее место для SVG-резки

Однофайловый браузерный интерфейс для подготовки и отправки SVG-траекторий на плоттер через Web Serial/CH340.

Поддерживается импорт `path`, `rect`, `circle`, `ellipse`, `line`, `polyline` и `polygon`, включая кривые Безье, дуги, группы с `transform` и несколько подконтуров внутри одного `path`.

Настройки траектории: размер листа, масштаб, поворот, зеркало, начало координат, вписывание в рабочую область, допуск аппроксимации, компенсация ножа, подъезд, overcut и разрешение координат. Используется HPGL: безопасный режим `Текущая точка плоттера` включает относительный режим `PR` и начинает резку от фактической позиции каретки без перемещения в центр листа. Поворот и зеркало задают ориентацию реза на станке (по умолчанию `90°` + зеркало — старт справа снизу), а на холсте макет показывается читабельно, независимо от этих настроек. Для замкнутого контура рез начинается с крайней угловой точки: к ней делается прямой подъезд (задаётся отдельно, мм) из отхода, чтобы нож выровнялся, а overcut проходит за угол и возвращается по той же линии. Скорость и усилие задаются на самом плоттере; команды отправляются через COM.

## Запуск

В Windows PowerShell из этой папки:

```powershell
python -m http.server 8080
```

Откройте в Chrome или Edge: http://localhost:8080

Перед первым проходом поднимите нож или установите перо. Начните с `HPGL`, `9600 baud`, разрешения `0,025 мм` и пробной резки на обрезке материала. Если плоттер не реагирует, попробуйте `DMPL`.

`Компенсация ножа` строит траекторию оси держателя с дугами разворота, а `overcut` добавляет проход за точку замыкания и возврат обратно. Физический вылет ножа выставляется только механически на держателе.
