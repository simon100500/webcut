# Cutline — рабочее место для SVG-резки

Однофайловый браузерный интерфейс для подготовки и отправки SVG-траекторий на плоттер через Web Serial/CH340.

Поддерживается импорт `path`, `rect`, `circle`, `ellipse`, `line`, `polyline` и `polygon`, включая кривые Безье, дуги, группы с `transform` и несколько подконтуров внутри одного `path`.

Настройки траектории: размер листа, масштаб, поворот, зеркало, начало координат, вписывание в рабочую область, допуск аппроксимации, компенсация ножа, подъезд, overcut и разрешение координат. Используется HPGL в абсолютных координатах: `IN` задаёт ноль в точке каретки (перекрестие на превью), каждая `PU`/`PD` — абсолютная точка; относительный режим `PR` прошивка станка игнорирует, поэтому не используется. Каретка паркуется в перекрестие вручную перед резкой. Поворот и зеркало задают ориентацию реза и применяются одинаково к предпросмотру и к командам: что на холсте — то и режется (WYSIWYG). Холст рисуется в ориентации станка — ось X (ширина листа) идёт вертикально, ось Y (подача) горизонтально, поэтому лист на экране лежит «альбомно», как в плоттере. По умолчанию `0°` / без зеркала; чтобы логотип лёг горизонтально, ставьте `90°` + зеркало (старт — правый нижний угол листа). Для замкнутого контура рез начинается с крайней угловой точки: к ней делается прямой подъезд (задаётся отдельно, мм) из отхода, чтобы нож выровнялся, а overcut проходит за угол и возвращается по той же линии. Скорость и усилие задаются на самом плоттере; команды отправляются через COM.

## Запуск

В Windows PowerShell из этой папки:

```powershell
python -m http.server 8080
```

Откройте в Chrome или Edge: http://localhost:8080

Перед первым проходом поднимите нож или установите перо. Начните с `HPGL`, `9600 baud`, разрешения `0,025 мм` и пробной резки на обрезке материала. Если плоттер не реагирует, попробуйте `DMPL`.

`Компенсация ножа` строит траекторию оси держателя с дугами разворота, а `overcut` добавляет проход за точку замыкания и возврат обратно. Физический вылет ножа выставляется только механически на держателе.
