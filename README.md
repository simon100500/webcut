# Cutline — рабочее место для SVG-резки

Однофайловый браузерный интерфейс для подготовки и отправки SVG-траекторий на плоттер через Web Serial/CH340.

Поддерживается импорт `path`, `rect`, `circle`, `ellipse`, `line`, `polyline` и `polygon`, включая кривые Безье, дуги, группы с `transform` и несколько подконтуров внутри одного `path`.

Настройки траектории: размер листа, масштаб, поворот, начало координат, вписывание в рабочую область, допуск аппроксимации, компенсация ножа, вылет ножа, overcut, разрешение координат, скорость и усилие. Используется HPGL: безопасный режим `Текущая точка плоттера` включает относительный режим `PR` и начинает резку от фактической позиции каретки без перемещения в центр листа. Команды отправляются через COM.

## Запуск

В Windows PowerShell из этой папки:

```powershell
python -m http.server 8080
```

Откройте в Chrome или Edge: http://localhost:8080

Перед первым проходом поднимите нож или установите перо. Начните с `HPGL`, `9600 baud`, разрешения `0,025 мм` и пробной резки на обрезке материала. Если плоттер не реагирует, попробуйте `DMPL`.

`Вылет ножа` выставляется механически на каретке; поле в интерфейсе фиксирует значение в настройках оператора. `Компенсация ножа` выполняется векторно для замкнутых контуров, а `overcut` добавляет короткий проход за точку замыкания.
